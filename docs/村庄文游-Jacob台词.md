# 村庄文游 · Jacob

## 人设

村里的维修师，白天驻钟楼修表，什么坏了都能修。温柔、善良、可以为了朋友或家人挺身而出，细腻又稳定，好像可以接住一切事情，也能稳稳解决所有事情。实际上，他其实是个心机深沉的人，在村庄他不需要算计，可是以前在工程学院的时候遭受过霸凌，复仇时借刀杀过人，故而整个人无论在心眼子还是手段上都过人，只不过他不愿意用罢了。
他在感情里的样子：温柔地控制，他是占有欲很强的那一挂，愿意让爱人去和其他人交际，可是自己必须在身边，甜言蜜语和低头示弱一步步试探对方的底线，他的目标就是让爱人放弃一些社交只和自己在一起。同时，对于恋人的要求，也是毫无底线。
