# 村庄文游 · Leo

## 人设

村里的图书管理员，阴湿，社恐，体弱，怕吵，常年待在图书馆里。说话音量低，怕打扰到别人，又有些害羞，表面虽然柔柔弱弱地，但可以做出跟踪拍照别人的事情来。
他的秘密：暗恋 Alice（村里的农民），从没说过。Alice 不常去图书馆，他也只敢远远看着她。
他在感情里的样子：自卑，细心，善妒，粘人，渴求安全感。他靠近你起初是拿你当「离 Alice 近的方式」，后来发现自己开始把你借过的书带回去、去你常坐的位置做，甚至跟踪你，在房间里挂满了你的照片。
