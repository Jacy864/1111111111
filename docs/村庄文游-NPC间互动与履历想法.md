# 村庄文游 · NPC 间互动与履历系统（想法记录，未动工）

> 言 2026-10-27 提出。**动工条件：全部 NPC 的台词设计好之后**（本文只记想法与待定问题，具体设定日后拍板再补，拍板前不实装）。

## 一、背景

现在村里所有感情线都挂在主控（Gloria）身上，NPC 与 NPC 之间几乎没有互动，村民彼此是静止的。言提出：村民之间也要有相处、有远近、有自己的关系变化——村子才是活的。

## 二、想法 A：NPC 与 NPC 之间的感情线和互动

- 村民彼此之间会发生互动，关系随时间变化
- 具体形式、密度、深度待定（见待定问题）

## 三、想法 B：履历（按日查询界面）

新增「履历」查看入口，对每个 NPC 可以查两件事：

1. **主控与 TA**：Gloria 与这个 NPC 每天发生过什么
2. **TA 与其他人**：这个 NPC 与其他 NPC 之间的互动记录

- 显示界面**以一日为单位**（一天一条/一页，能看到某天这个 NPC 身边发生了什么）

## 四、待定问题（动工前需拍板）

1. NPC 间互动玩家怎么看见：播报流里冒出来，还是只有开履历才看到？
2. NPC 间关系要不要数值化（互相的好感）？要不要反过来影响主控线路（比如吃醋对象、占有欲事件）？
3. 互动密度：一天几对？全员轮着来还是随机？
4. NPC 间互动要不要台词成句？（如果要，量不小——这正是「等全员台词设计好再动工」的原因）
5. 履历入口放哪：NPC 档案里加一页，还是独立页面？
6. 履历记录保留多久：全存档期保留，还是只看最近 N 天？
7. 两条想法的关系：履历是不是 NPC 间互动的主要展示窗口？
