## 总则（全线路通用）

- **门槛体系**：事件按 友情度/爱情度 双门槛解锁；秘密线事件额外要前置 flag。数值以实装调平为准，这里写档位。
- **告白机制**【2026-10-16 言定案】：爱情 60 + 友情 60（各线微调）+ 该线关键事件走完 → 触发告白事件。中世纪背景无「恋人/男女朋友」身份，告白只有两种结果：
  - **接受** → 对方开始有求婚念头（衔接婚姻系统）
  - **拒绝** → 对方不再有求婚念头
  - 原「定下来（终局画面）/先这样（恋人状态）」二选作废；NPC 专属终局结局已作废（拍板记录 2026-10-15 第 13 条）
  > 【2026-10-15 变更】Vivienne 线已改求婚/婚礼制，不走终局结局（见其一节）；「定下来=终局画面」对其余稳定型 NPC 的适用性待议。变更与待议项汇总见《村庄文游-拍板记录.md》。
- **多线并存**：不锁线，你可以同时养多条（药王谷式自由）；但部分事件有刺（Leo 线里代问 Alice、Asher 线撞骑士），选了会记账。
- **尸毒三人组**（Bess/Olivia/Jacob，第二三轮出）：感情线与救治支线绑定。救成才开 good ending；人死了线就断，不出结局，村庄继续。
- **骑士**：感情线即主线（E2 系），第三轮单独整理告白事件与 E2b 的衔接。**E2b 依旧完全隐身，本方案文件也是唯一记录处，游戏内零提示。**
- 尺度：成人内容按 §0 尺度写，文本点到即止，不写露骨（Asher 寻欢/背德台词是否生成待拍板，见拍板记录 2026-10-15）。

## 一、Vivienne（牧师，30）

> 2026-10-11 重做：言重写人设（重欲傲慢、毫不掩饰、情报独占），旧版「忏悔拉扯」线作废。
> 【2026-10-16 言令删除】【情报的价钱】【忏悔室】出档（未拍板内容不得入档）；情报相关机制以「每日情报·活报纸」为准（拍板记录 2026-10-15）。
> 【2026-10-16 言拍板】【交换夜晚】保留；告白事件删除（无恋人关系系统，本线终点直接为反向求婚）。

**走向**：她追你。黄腔是日常，兜底是真心。表面是全村最体面的引导者，对你一个人重欲、傲慢、毫无顾忌。核心张力：一个把欲望管理得井井有条、对谁都能下手的人，第一次想独占一个具体的人。

### 事件
1. **【夜里回来的人】**（爱 30 + 友 50，夜间撞见型，需夜出系统，第二批实装）
   你在教堂外撞见她刚回来。她不躲，反过来调戏你（台词按新人设：坦然、黄腔、毫无悔意）。
   三选：**装没看见 / 追问 / 陪她进教堂**。追问升温最快；装没看见她会觉得无趣，隔几天换个法子来撩你（变体 flag）。
2. **【交换夜晚】**（爱 60）
   她打探到一条你正需要的东西（按你挂着的别线给：尸毒的风声 / Lee 的线索 / 骑士的损耗），开价是一整晚。接受 = 寻欢入口事件；拒绝 = 她头一次不高兴，但情报照给（她的兜底在这里显形，玩家第一次看见代价是假的）。

### 求婚·婚礼【2026-10-15 言拍板：本线不走终局结局】
Vivienne 是稳定因素，不像骑士真能出人命——结婚后游戏继续。
- **她反向求婚**：不等玩家开口，话包在日常里说完就当你答应了；玩家有确认/再想想的选项（交互细节实装时定）
- **婚礼**：教堂办，由教堂其他修女主持（村庄有背景居民修女）
- **婚礼上/婚礼后**：高好感角色出现特定台词（台词后补）；婚后日常池切换已婚版
- **婚内出轨寻欢** → 背德台词机制（框架 §16，台词后补）
- 旧「结局【神母】」文本（收心/学哄人变体/失败支更疯）不再作为终局；文本处置待拍板（候选：改写为婚礼誓词或婚后素材）

## 二、Levi（农民·养殖师，25）

**走向**：全村最软的好人，谁都能使唤。感情线核心是他第一次被人认真对待。他的 M 倾向写成「不敢要」的形状：让他上瘾的是被你专门对待。线整体是暖的，全村最稳。

### 事件
1. **【自己的田】**（友 40，农田闲聊触发）
   你问他：「你帮所有人，你自己的田谁管。」他愣了一下：「我的長得慢就慢吧。」
   可选「明天我来管」→ 记 flag：你开始照顾他（后续他的播报事件变化）。
2. **【打斗之后】**（友 50 + 打闹过 3 次）
   某次打闹你按住他，他安静得反常。你问，他说：「沒事。起來幹活了。」
   当晚播报：Levi 一个人在田里坐到很晚。
3. **【村外】**（爱 40，秘密线入口；需探险系统，第二批实装）
   约「去森林帮个忙」。骑士不能离村，出了村界只有你们俩。他答应得很快，快到自己也愣住。林子里他说实话：「從小就這樣。他們打我，都是順手的。你是專門的。」
4. **【命令他休息】**（爱 55，互动菜单新增）
   你命令他歇一天。他听话得像换了个人。当晚他送来一筐东西，附字条，字很丑：「今天是我今年最開心的一天。」

### 告白（爱 60 + 友 60 + 事件 3）
收工的田埂上：「我知道我不該想這些。你要是嫌煩，我照樣幫你幹活。」
→ 接受 / 拒绝（接受＝他日后会有求婚念头；拒绝＝不会有）。

### 结局【一亩地】
文本方向：你的田和他的田并成一亩。播报里他照旧是谁都帮的 Levi，只是收工先回你家。
变体：从没用过强硬互动（M 线没碰）→ 温和版结局：他始终没说出口的那部分，你们心照不宣。
备注：无 BE。打闹线友好，骑士应激风险按总则（户外公共场合）。

## 三、Leo（图书管理员）

**走向**：心里有 Alice（固定底色）。你靠近他，他先是拿你当「离 Alice 近的方式」，后来发现自己开始整理你借过的书。他的爱法：记录、观察、不敢碰。这条线要正面处理三角。

### 事件
1. **【登记本】**（友 40）
   你发现登记本上你的名字被描过一遍。他抢回去：「墨透了。我補的。」
2. **【Alice 还书那天】**（爱 35，你在场）
   你亲眼看见他对 Alice 多擦一遍柜台，看见你进来又把抹布收起来的样子。当晚播报：图书馆的灯亮到很晚。次日他对你冷淡一天（他在羞耻）。
3. **【摊牌】**（爱 50，他主动）
   「Alice 的事，你看出來了。」三选：
   - **帮他去问** → Alice 拒绝（若你 Alice 线进度更高，她会反问 Leo 是不是有别人了，刺回去）；之后图书馆闭门 3 天，你去敲门，他开条缝：「我就知道會這樣。」
   - **劝他放下** → 他说「放著吧，反正也不重。」（flag：未解，结局变体）
   - **「我不管」** → 冷处理，线照常但少了这段清算
4. **【常来的人】**（爱 60）
   里侧最好的位置放了块小木牌，没字。你问是谁的：「常來的人。就你。」

### 告白（爱 60 + 友 55 + 事件 3 任一走向完成）
闭馆后他递给你一本书，是你第一次借的那本。扉页有铅笔字，写了又擦过。
「擦掉的那句，和現在這句，是一個意思。」（铅笔字内容即告白）
→ 接受 / 拒绝（接受＝他日后会有求婚念头；拒绝＝不会有）。

### 结局【闭馆时间】
文本方向：图书馆到点关门，钥匙多一把在你这。登记本最后一页是你们俩的名字并排。
变体 A：事件 3 选「劝他放下」→ 结局多一段：Alice 来还书，他全程没有抬头。
变体 B：你与 Alice 确定过关系再回头走 Leo 线 → 登记本上有一页被撕掉了，他始终没问。
BE：帮问被拒 + 之后冷落他 30 天 → 线断。他对你恢复了对待所有借书人的客气。

## 四、Asher（16 · 不出游戏终局）

**走向**：这条线不是恋爱线，是「怎么接住一个喜欢你的人」。核心抉择：家人框架 / 守望约定。他的拆散行为随你与骑士的进度升级，感情线要正面处理他和骑士在你这里撞车。
**设计位**：Asher 线不出「游戏终局画面」——他是村庄的一部分，不是出口。他的「结局」是关系定型，游戏继续。

### 事件
1. **【第二张床】**（友 50，夜间家中随机）
   你听见他翻身。他说：「床的事。我就是還沒習慣有自己的一張。」
2. **【井后面的身影】**（你夜间外出 2 次后；需夜出系统）
   播报：夜里你出门，井后面藏着一个人。是 Asher，兜里揣着弹弓。
   他嘴硬：「我散步。」
3. **【撞车】**（骑士爱情 ≥ 40 时触发）
   他当面问：「那個瓷的，知不知道你晚上去哪。」
   三选：**如实说 / 敷衍 / 反问他在想什么**。如实说 → 「行。你知道自己在幹什麼就行。」之后他的拆散升级成自暴自弃式（故意当着你和 Alice 打得火热）。
4. **【发烧】**（爱 50，雨天随机）
   他淋雨发烧，你照顾一夜。他说胡话，内容是两岁那年的村口。醒来全忘了，问你：「我說什麼了。」
   你选：说 / 不说（说了他沉默很久；不说这个秘密归你保管）。

### 告白【不想当你的孩子】（爱 60 + 友 70 + 事件 4）
他生日那天（村里给他过，「大家的孩子」），夜里回家：
「全村都說我是大家的孩子。」停了一会儿。「我不想當你的孩子。」
三选，各定型一个结局分支：

- **a.【约定】**「等你长大」
  不确定关系。他床边多了一个自己钉的架子，放你的弓。文本方向：他开始学着照顾你，而不是跟着你。
- **b.【家人】**「你永远是我家人」
  他难过了三天，之后真的变成了家人。只是每年生日，他喝的酒比上一年多一杯。苦，但诚实。
- **c.【让位】**（仅当你骑士线爱情度高时出现）「我心里有人」
  他说：「我知道。我早就知道了。」当晚他睡回第二张床，从此不再拆散。这条不锁骑士线。
