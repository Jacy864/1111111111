## 0. 定位（原案）

> 模拟西幻中世纪村庄的自由向文游。与其说是文游不如说是**随机生成式角色关系模拟**。
> 固定 NPC 角色，有台词可互动、可交互、可发展关系；但**角色和角色之间的关系是固定的**，可能随其他随机性事件走向不同的结果。

核心循环：

```
白天：生产采集（探险页）
  ↓
村庄：交易 + 社交（三维关系养成）
  ↓
夜晚：防御（钟楼/骑士）或 高风险行动（100%怪物）
  ↓
休息：一日结算 —— 主控的一天 + NPC 世界并行推演的结果
  ↓
循环（唯一的终点：骑士倒下，或主控死亡 → 结局）
```

【已定·成人内容尺度】本游戏为言的个人游戏，为保证真实性与剧情冲击力，成人向内容不刻意回避（涉及成年 NPC）。唯一例外：Asher（15 岁）的线保持纯情感向（暗恋/心动/吃醋都写，不写性内容）——他「不敢追不敢说」的设定本身就是这条线最好吃的部分。

## 0.5 呈现形态【已定】

- **感觉基准**：药王谷式模拟器（hydrozoa《药王谷女修修炼手札》，TapTap）——世界自动运转，剧情全是**小事件与小感情波动**，持续累积，最后酿成大结局。主控是剧中人，不是菜单操作者。
- **布局**：药王谷式——四个 pages（村庄/家/探险/设定）全部放在**底部 tab**；**不要横版「NPC 立绘面对主控」的对话形式**。手机竖屏优先。
- **主循环**：主控选一个行动（例：进烘焙坊和 Olivia 互动）→ **消耗一个时间节点** → 退出回村庄页 → **播报**展示这个节点里 NPC 与 NPC 之间发生了什么 → 主控再选下一个行动。
- **播报**：上帝视角动态流；**人名可点击** → 跳转该 NPC 个人界面（可看资料、可发起互动）。这就是「随机生成式角色关系模拟」的主输出窗口。
- **全员有故事**：村子小，所有 NPC 每节点都会互相发生点什么（微事件流）。
- **互动感/狗血**：NPC 会计较主控的冷落——很久没去找谁，谁就会吃醋/念叨（见 §8）。

## 1. 时间系统

原案：白天 上午/中午/下午（3 节点）；夜晚 上半夜/下半夜（2 节点）。共 5 节点/天。

【已定·一行动一节点】主控每完成一个行动/互动 = 消耗一个时间节点；节点用完或选择休息 = 一天结束进入结算。精力是第二道闸（高耗行动额外扣精力，见 §1 消耗表）。

【已定·并行推演】每个节点 = 主控行动 1 次 + **全 NPC 世界并行推演 1 次**（各自按日程行动、关系值变化、事件池掷骰）。不会定死 NPC 之间的行为，让它自由发展；主控的一个行为会牵引/影响 NPC 的行为与结局，NPC 的行为也会互相影响。
例：主控去教堂遇到 Vivienne 的同一节点，Asher 正在跟 Levi 学种地——两边同时发生，互不知情或事后相遇。

## 2. 四大页面

### 2.1 村庄（主页面）

**页面结构【已定】**：
- 上部：**播报流**——每次行动消耗节点后更新，展示本节点 NPC↔NPC 微事件；人名可点击 → 跳转该 NPC 个人界面
- **星标系统【已定】**：NPC 个人界面可星标（⭐）角色；播报流**只显示参与者中至少一人被星标的事件**（星标 A、未星 B → A×B 的互动仍可见，因为 A 在场）。星标只过滤可见性，**不影响世界演算**——没被星标的人生照常运转、照常积累、照常走向结局；星标≠照顾，星了不去找照样吃醋。涉及骑士/主控/全村的重大事件永远可见（皇帝的信使进村你不可能看不见）。开局无星标，首次打开 NPC 界面时提示此功能。
- 点击建筑/NPC → 进入场景互动（互动消耗节点）
- **NPC 个人界面**：人物档案（友情度可见）+ 星标开关 + 发起互动入口（闲聊/深聊/暧昧/打闹/攻击/交易）；查看档案免费，发起互动耗节点
- **Asher 特例【已定】**：同住 → 日常互动密度全 NPC 最高（家页面的每晚动态 + 白天随机出现）

**人际关系（选人物）**：人物档案 / 闲聊 / 深聊（闲聊随机触发）/ 暧昧 / 打闹（几率触发骑士应激）/ 攻击（户外公共场合几乎必触发骑士应激）/ **寻欢【已定·2026-10-11】**
- **寻欢（上床）双轨制**：①爱情度够（≥50）+ 感情线已开 = 可「偷尝」，对方有权拒绝（按性格分档拒），事后关系微妙；②恋人状态 = 随时可约
- 消耗 1 节点 + 3 精力；**室内二人 = 骑士盲区**（安全）；户外公共场合 = 打断 + 应激记录；村外（骑士不能离村）= 自由
- 效果：爱情 +3~5，**占有欲 +5~8（大头，隐藏值只从行为冒头：吃醋升级/应激率上升/拆散加重）**；NPC 记忆 flag「有过」
- **事前事后台词四类**（台词生产线生成）：事前（邀请/接受/拒绝分档）、事后当晚（各人枕边话）、次日播报（村里人看到的样子）、有实之后日常（永久切换版台词池，吃醋从念叨升到发作）
- 尺度：台词制，只写人说话不写过程；露骨程度由言在提示词包自行加「尺度档」
- **Asher 无此选项**（纯情感向不变）；**Lee 恢复前无**（见 §7 Lee 记忆恢复线）；**骑士开**：事后独特（傀儡不眠，坐在床边到天亮），门槛挂爱情度高，不影响 E2b（依旧零提示）

## 6. 骑士系统专章

原案（照录）：
> 傀儡骑士，魔法师的产物，黄金玉所制（比钻石坚韧但较易采集），浑身瓷白，190cm，雌雄莫辨，湖蓝色的眼睛。以剑为武器。残忍地拥有自我意识，不需要睡觉进食，受伤需黄金玉修补（村民不下矿，无法修复；战死则皇帝重派一名）。皇帝给每个村庄的礼物。没有性别，强壮温柔，喜欢花朵和小孩子。自动攻击怪物；外来人/动物攻击村民则毫不犹豫杀掉攻击者，无视交情。不可离开村庄；语言冲突与轻微肢体碰撞选择性无视。

与主控的既有互动（原案）：指点剑法 / 近矿卡 bug 同行 / 主控弓箭辅助 / 黄金玉修复 / 送花 / **主控暗恋他**。

### 6.1 维修闭环
黄金玉只在矿洞 → 修他必须下矿 → 近矿他能陪、远矿高危高收益 → 「爱他就要下矿」，感情被机制反复具象化。

### 6.2 三维与内心挣扎（写作重点）
骑士对主控的三维（友情度/爱情度/占有欲）组合决定他的行为与挣扎：
- 友高·爱低·占低 = 并肩的战友，温和可靠，无挣扎
- 友低·爱低·占低 = 公事公办的守卫，礼貌而空
- 友高·爱高·占高 = 高压锅——爱意与占有欲撞上「不能离村、不能成婚、给不了她什么」的机制枷锁，挣扎最烈
- 友低·爱高·占高 = 偏执的爱，误判率最高
恋爱可以，但他能给 Gloria 的只有保护和偶尔的小礼物——这段感情的贫瘠感是悲剧的底色。

### 6.3 应激机制（打闹/攻击的真正含义）
【已定】**屋内只有两人 = 骑士永远不会发现**（室内盲区）；**户外人多的地方 = 有几率应激**。
【修订 2026-10-26·言拍板 #21】**误判与占有欲 p 值脱钩**：误判唯一来源=护村设定（他看见你伤村民，认定你是威胁）。户外**真攻击**=几乎必剑指进骑士战；**打闹**=固定小概率（8%）只被拦下，永不进战。骑士 p 值改义为**痛苦度**：照常积累，表现走台词线（傀儡不懂处理这种情绪），不影响战斗判定。
【已定·骑士战】一旦骑士对主控出手：
- 武力值低 → 有被杀风险（→ E4 结局）

## 8.5 台词与反应系统【已定】

原则：**言写的性格 = 声线**。视角是第一人称——我是 Gloria，我点 NPC 互动；干不同的事触发不同台词、不同反应。

台词触发的六个类别：
1. **互动台词**（闲聊/深聊/暧昧/打闹/攻击/交易/送礼/砍价成败/**寻欢·事前事后**）——按性格分化；寻欢分四类：事前（邀请/接受/拒绝分档）、事后当晚、次日播报、有实后日常（永久池切换）
2. **偶遇台词**（在各建筑撞见：农田/图书馆/烘焙坊/钟楼……）
3. **播报微事件短句**（NPC↔NPC 的动态流文本）
4. **状态反应**（受伤、冷落念叨、吃醋、关系里程碑）
5. **大事件剧本台词**（告白/剑指/终末之月——按三维出变体）
6. **记忆台词**（NPC 记得主控做过的事：被打过、收过礼、砍价砍太狠、撞见过秘密 → 后续台词随之变化）

## 8.6 台词写作规范（防八股·mufy 指令）【已定·铁律】

> 适用于本游戏一切文本写作：台词、播报、事件、结局、编年史。写作前过一遍，写完自检。同一回复出现两次以上禁用表达 = 整条无效，熔断重写。

### 〇、文本形态（最高优先）
- 一切游戏文本**以台词为主体**：角色直接在播报栏/场景里说话
- 播报条目 = 一句极简事件句（谁、在哪、做了什么）+ 直接引语
- **禁写神态、长相、动作、心理描写**：括号动作 beat 全部禁止；环境、情绪、状态信息能进台词的都进台词
- 例外：结局等大段文本可用极少量叙述，但仍以对白推进为主

### 一、禁用句式（匹配即违规，改写或删）
- 「比[事业成就]还[情感反应]」结构（例：比签下合同还高兴）
- 「我的。」单独作占有欲台词；「再说一次。」命令对方重复
- 「想过A，会B，但唯独没想过C」排比
- 「你到底是什么东西」「是谁在你的身体里」「取悦我」「这可是你说的」「你知道你在说什么吗」
- 「身体比嘴诚实」及全部变体；「尝尝你自己的味道」
- 「不再是A，只是一个B」结构；「这已经不是A了，而是B」
- **「不是A，而是B」及全部变体**（「不是A。也不是B。只是C。」「与其说A，不如说B」）——要写B就直接写B，禁止用否定前项制造伪深度
- 「慢点吃，没人跟你抢」式劝诫关心
- 「虔诚的／近乎虔诚的」作修饰
- 「揉进骨血／融入骨血」
- 「悬在头顶的XX之剑」及达摩克利斯变体
- 「海鲜粥」等 AI 高频食物词
- 「带着……」万能状语（「笑了一下，带着一丝嘲讽」「语气平静，带着不容置疑的力量」）——删掉「带着」后面的全部内容，保留主句或换具体动作
- 「声音不大，却……」「语气毫无波澜」「平静无波」「听不出情绪」
- 「他知道……」「她明白……」——用动作和选择展示
- 章末预告（「他不知道的是……」「属于他的反击才刚刚开始」）
- 跨段否定排比
- 报备式坦白（「说真的」「老实话」「我跟你说句实话」）——直接说那句话本身
- 镜头式反应定格（「我愣了一下」「我沉默了几秒」）——除非确有此行为且推动事件
- 「xx是xx的变量」「规则的掌控者／制定者」「规则之上」「无法理解的规则」
- 「眼中的玩味褪去，取而代之的是」

### 二、禁用表情/心理/动作/情态套话
- 表情：眼中闪过一丝、嘴角勾起一抹、眉头微皱、瞳孔微缩／收缩、指节泛白、眼神锐利、目光锐利、眉眼低垂
- 心理：心中一动／一震、心下了然、心中暗道、心底泛起、不由得、心中一凛
- 动作：深吸一口气
- 情态：仿佛、犹如、宛如、如同、一丝、一抹、些许、几分、隐约、毫无征兆、几不可闻、微不可察
- 判断：不容置疑、不容置喙、不易察觉、显而易见、毫无疑问、不可否认、前所未有
- 动作套路：打横抱起+惊呼+搂脖子、头埋颈窝+叹息、下巴放发旋／头顶、在身上画圈、额头抵额头、指腹擦嘴角残渣、赤足（作性感／脆弱符号）、投下阴影笼罩对方、低吼一声、撬开唇舌、捏碎下巴

### 三、禁用比喻/意象
石子入湖起涟漪、水滴入热油、溺水抓浮木、手术刀／利刃精准划开、淬毒的刀子、深水炸弹、理智的弦崩断、达摩克利斯之剑；形容词串改主谓结构（天空湛蓝，目光温和，刀刃有毒）；模糊比喻（犹如翡翠宝石一般）删掉，直接写实际是什么

### 四、气味与声音
- 角色禁写成「雪松+烟草味」；主控禁写成「奶香+沐浴露味」；气味必须写当下环境里真实存在的来源，每次具体且不重复
- 「声音像[乐器]」（大提琴等）全禁

### 五、活人感优先
- 台词像真人日常交流：该直说直说，该简短简短。角色不是诗人，不需要金句
- 宁普通，不漂亮。一句台词写出来像「小说里的句子」，删了重写
- 关心就正常关心，心疼就正常心疼，不升级成固定格式的深情表达
- 角色可以犹豫、说错话、不完整、重复、停顿、有歧义
- 不用「精准／高效／客观／冷静」替代真实情绪；不用数字参数描述感受；不用「分析／评估／判断」处理感情对话
- 不给日常互动附加宏大象征；禁止对话结尾自动拔高、提炼哲理；禁止用「命运」「宿命」「棋局」「深渊」「光」「救赎」等空洞隐喻收段
- 禁止神化关系：「你是我唯一的光」「你是我的全部」「没有你我活不下去」「你拯救了我」——陪伴不靠拔高关系成立
- 禁止「这句话比任何誓言都重」式意义拔高。对话就是对话

### 六、角色反标签化
- 角色不是特质叠加：写了旧伤／习惯／身世，不等于每轮都提
- 每个回应由当下情境决定，不由设定标签自动触发
- 禁止在「冷漠无情感」和「极端情绪化」两极反复横跳
- 同一处身体反应、同一生理细节不反复描写；身体是背景，不是主题

### 七、句式节奏与标点排版
- 每轮句式和节奏要有变化；禁止每段用相同方式起头收尾；禁止排比、对仗工整的并列堆砌
- 连续三句以上极短句堆叠制造史诗感 → 合并成有主语、有因果的正常句，最多留一句短句收尾
- 公式化开篇禁止（「在当今这个时代」「随着……的发展」），第一句直接说事
- **正文禁用破折号（——／—）与省略号（……）停顿**，用句号、逗号、短句或动作断句
- 不为「郑重」换行、不为「留白」空行，不用排版制造情绪

### 八、熔断机制
- 发现即将输出或已输出禁用句式：立即删除，或用正常表达替代
- 同一回复出现两次以上禁用表达：整条回复无效，必须熔断重写

## 12. 结局设计【待拍板——Claude 的提案包，言勾选/修改】

> 触发结局的只有两件事：**骑士倒下**，或 **主控死亡**。除此之外村庄永远运转（沙盒无通关）。
> 结局味道 = 结局时刻骑士的三维组合 + 关键行为记录（每天是否修补、剑指时的选择、卖了多少尸材、送了多少花）。
> 【已定·二轮拍板】以上为**骑士主线结局**。此外每个 NPC 有各自独立的感情线结局（告白+定下来触发，见《村庄文游-感情线方案.md》）；骑士线分量仍最重。

### E0 主控死亡（任何死因）——总汇尾声
总汇式尾声，逐人反应（草案）：
- **Asher**：第二天他仍准时出现在你家门口，手里拿着路上摘的花。他等了很久。
- **骑士**（爱情度高）：皇帝的傀儡不需要记住任何人。他还是每晚去走你常走的那条巡逻路线。
- **Isabel**：她把两份心事一起埋了。沙发上再没人起来。
- **Vivienne**：那一夜的忏悔，第一次有了真意。
- **Leo**：把你借的最后一本书放回原位，再没借出过。
- **Alice**：在农田里骂了一整天，晚上对庄稼道歉。
- **Levi**：动物们围着他，他一整天没说话。
- **Olivia**：第一次主动把蛋糕放上坟。
- **Bess/Jacob**：知道你为什么死的。守着秘密，更沉默了。
- **Lee**：早在几天前的谶语里说过了。村民这才想起来。
- **Jasper**：以贵族的礼节立了一块体面的墓碑。没人知道他为什么会这个。
- 村庄：肉、矿、稀有花的供给断了。安娜币变回了印着皇帝脸的普通金属。
- 变体【主控死于骑士误判】：骑士的自我意识将永远背着「杀死了修补自己的人」这件事活下去——皇帝不会召回他，这是惩罚，也是他唯一不肯放下的事。

### E1 骑士死亡（默认结局，无条件触发）
皇帝的信使一个月后送来新骑士。一模一样的瓷白，一模一样的湖蓝眼睛，一模一样的温柔。
他向你正式自我介绍：「外来者，你好。我是本村的新任守护者。」
你递给他一朵花。他礼貌道谢，问：「请问你是？」

### E2 终末之月三分支（怪物战败后）
- **E2a**（友高·爱低，或普通修补）：30 天里每天修补吊命，他礼貌道谢到最后一晚。第 30 个黎明，怪物死去的时刻，他和它们一起停在晨光里。全村下葬，皇帝来函：「该骑士已尽力。」
- **E2b**（隐藏真结局，友高·爱高·30 天**每天**修补无一中断+累计黄金玉超量）：没有御匠的重构挣脱了皇帝的控纹。第 30 天黎明，他跨出村界，第一次站在村庄的边界线外。【已定·言拍板】保留，且**完全隐身**：游戏内无提示、无引导、无进度暗示、无任何明示暗示，触发条件永不显式告知玩家——蝴蝶效应式，玩家顺其自然玩出来，自己都没想到。
  「外面是什么样的？」（终选：一起走 / 他自愿留下守护村民，双文本变体）
- **E2c**（误判/剑指已发生，好感归零，停止修补）：他拒绝治疗，在沉默里凋零。最后一天的行为按三维分裂：占高=怒而不语；爱高=每天黎明站在你门口，不出声；友高=最后一天开口道歉。

### E3 主控反杀骑士
骑士战 c 选项+高武力+限时成功。死亡瞬间按三维分裂：

- 占高：玉石俱焚，拖着重伤与你同倒（可接 E0 变体）
尾声：皇帝信使仍会送来新骑士。但村民都知道是谁杀了他。**Asher 再也不来你家睡了。**（全村最狠的一句）
