- 对话直接引语或旁白式反应皆可，与现有互动台词（闲聊/暧昧/打闹池）同一格式

### Asher

- 摸摸头：①「别总把Asher当小孩揉头发。虽然……虽然也没有很不舒服就是了。」②「头发乱了，Gloria得负责给小Asher顺回来，不许用手胡噜。」③「别揉了嘛。要是把小Asher揉矮了，以后谁来帮Gloria扛柴呀。」④「Gloria的手心好暖。……再摸一下下就好，好不好嘛。」⑤「每次都这样。小Asher明明比你高了，怎么还总是够得着头顶……」
- 拥抱：①「……突然抱过来做什么。不过，小Asher不讨厌就是了。」②「这样贴着好舒服。Gloria身上有太阳晒过的味道，再抱一会儿嘛。」③「好啦，小Asher也抱抱你。别怕，以后都有我在呢。」④「手臂酸不酸呀？要是累了，换小Asher来抱着Gloria好不好。」⑤「被Gloria抱着的时候，就觉得今天切麦草一点也不累了。」
- 亲脸颊：①「Gloria怎么不讲道理，突然搞偷袭……」②「犯规。这绝对是犯规……」③「不就是、不就是碰了一下嘛，谁、谁怕谁了……」④「Gloria，离太近了……心跳得好快，你听见没有……」⑤「明明说好等Asher再长大一点的……Gloria怎么总是这么心急。」
- 依偎：①「好安静。要是时间永远停在现在就好了，Gloria。」②「床太冷了。小Asher只靠一会儿，不许赶Asher走……」③「明天还要去Levi田里拔草。Gloria别吵，让Asher再靠一会胳膊。」④「没点灯的夜里，Gloria是Asher唯一的亮光了。」（§8.6 破例保留）⑤「再赖一小会儿。就一会儿嘛……」

### 骑士

- 摸摸头：①「手会冷吗。我的头盔和头发都是凉的……你可以多摸一会儿。」②「瓷壳摩擦的声音听起来有些硬……如果你喜欢，我可以把头再低一些。」③「村里的孩子们也喜欢摸我的头。但只有你摸的时候，我觉得这里很安静。」④「别收手。我不介意。」⑤「你摸得这样轻……我是不会碎掉的，可以再用点力没关系。」

- 亲脸颊：①「刚才碰到的地方很凉吧……下次可以先贴一下我的手心暖一暖。」②「这是村里表达亲密的方式吗。那我……下次是不是也可以这样碰碰你。」③「被你碰过的地方，黄金玉填补的痕迹好像有些发烫……请不要突然这样。」（原稿「金粉」改「黄金玉」）④「……你刚才碰了我的脸。」⑤「这是只属于我们之间的接触吗……如果是，我每天清晨都会在这里等你的。」
- 依偎：①「天快亮了，前线的怪物都退回林子里了。你可以靠着我再睡一会儿。」②「我的肩膀不够柔软……但只要你需要，我可以一直保持这个姿势不动的。」③「窗外的夜风很大。靠在我身后吧，我可以把所有风都挡在外面。」④「靠着吧。我在这里。」⑤「屋里太暗了。靠在我身上吧，我的眼睛会替你守着这片夜色。」
