## 五、入库流程（同 Lee 台词库先例）

1. 感性模型按提示词包生成 → 言挑选
2. 入库前过一遍「入库转换」：村庄里不存在的物件/场所、§8.6 违例（破折号、省略号、神态心理、空洞比喻）先改再入
3. 入 src/data.js 对应键（chat/flirt 从平铺数组换成 `{low, mid, high}` 对象，引擎已兼容两种格式）
4. `bash build.sh` → 桌面小游戲/ 替换 index.html
