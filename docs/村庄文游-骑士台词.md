## 入库时对原稿的转换（不符合村庄设定/E2b/§8.6 的处理）

| 原稿 | 转换后 | 原因 |
|---|---|---|
| 瓷砖如果裂开（闲聊60+） | 瓷壳如果裂开 | 它是傀儡，材质是瓷壳（对齐全篇「瓷壳/瓷面」用词） |
| 我在西边山谷见过（闲聊60+） | 我在界线边的林子里见过 | 它不能离开村庄，山谷去不了；删「天亮」（天亮它刚从前线回，找花是白天的事） |
| 拿药膏涂在瓷面上（深聊） | 用金粉补在瓷面上 | 修补闭环是矿洞黄金玉→金粉→修补，治愈它用金粉 |
| 我昨晚在村口站了很久（暧昧中1） | 我昨晚在前线守夜。天亮回来的时候 | 夜里它在前线杀怪，不站村口 |
| 如果有一天我可以离开这里，我想跟着你走（暧昧高3） | 你去过的那些地方，我一个都没去过。你跟我讲讲村外的事，我听着，就当自己也走过了 | **E2b 禁忌**：「想离开」直指禁忌清单的离开/自由主题（觉醒宣言范畴），改成「不懂但认真」的问询式向往 |
| 十五岁的少年（吃醋2） | 十六岁的少年 | Asher v2 = 16 铁律（拍板记录 2026-10-15 #4） |
| 村口没有人在看守（吃醋1） | 村里没有别人 | 夜里它在前线，村口本就不归它看守；改成报告式事实「只有你们两个」 |
| 最近三天下山（冷落1） | 最近三天回村 | 探险是出村去森林矿洞，不是下山 |
| 广场的台子上（送花低1） | 广场的石桌上 | 对齐村内实物（它自己闲聊里说的石桌） |
| 插在胸口的金饰缝隙里（送花中2） | 插在胸甲的缝隙里 | 对齐既有播报「胸甲的缝隙里别着那朵花」 |
| 我今晚想待在你的房间里（邀请2） | 天亮之后，我想待在你的房间里 | 夜巡时间自洽：夜里必须在前线，天亮交班后才能进你屋 |
| 今晚谁也打扰不了我们，我就在这里陪着你（事后3） | 天也快亮了，我就在这里陪着你 | 「今晚陪你」撞夜巡；改为天亮回来后说（怪物进不了房屋+晨起怪物死亡，时间自洽） |
| 清理完村口那几只怪物（偷尝4） | 清理完前线的怪物 | 它夜里的主战场在前线 |
| 在你房里待到半夜（偷尝5） | 在你房里待到天黑 | 天黑它就得去前线，待不到半夜 |
| 你身上的香味（偷尝2） | 你身上的味道 | §8.6 模糊香味禁令；改成明确指昨晚残留 |
| 每天夜里都在你屋里过夜（恋人4） | 每天天亮从你屋里出来 | 夜里它在前线；天亮回来进你屋才自洽，被全村看见的画面感不变 |

保留不动（核实过设定）：河边的怪物体液、帮凿矿石、钓鱼、扛木头、烤肉搬运、湖蓝色宝石眼睛、「住手。」、深聊「我不明白什么是离开」（表达的是不懂，不是想走，在「好奇可以」的范围内）。
